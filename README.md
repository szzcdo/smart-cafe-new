# Smart Cafe Customer App

## User Role

Customer

 

## Problem

Customers often queue before ordering and cannot easily browse menu items.

 

## Goal

Allow customers to register, login, browse products and place orders.

## MVP Features

- Register
- Login

- View Menu

- Place Order
  
- Logout
  
 

## Technologies

 

- Kotlin

- Jetpack Compose
  
- Firebase Authentication
  
- Room Database
  
 

## Acceptance Criteria

 

Given a registered customer

 

When they successfully login

 
33
